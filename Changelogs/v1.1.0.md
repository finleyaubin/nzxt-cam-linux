# NZXT CAM Linux v1.1.0

## LCD display
- One free-form scene editor replaces the fixed layouts. Add rings, gauges, bars, history graphs and text, then drag and resize them on a live preview.
- Text supports `{cpu}`, `{gpu}`, `{liquid}`, `{pump}`, `{sensorN}`, `{time}` and `{date}` variables, with editable logo text and size.
- Sensor picker, themes and a gallery, plus thickness, rounded ends and gradients for gauges, rings and bars.
- Photo or GIF backgrounds, GIPHY search with API keys in settings, and GIF dithering.
- Rotation in 0 / 90 / 180 / 270 degrees, applied in software with a persisted mount offset.

## Sensors
- Selectable CPU source, three bindable sensor slots and `nvidia-smi` GPU readings.
- Non-temperature sensors with per-slot units, and add/remove sensors with full-scale values.

## Config and CLI
- Versioned, validated config. An unparsable file is kept as `config.json.bad` and the error says where it failed.
- Saved layouts, plus `--lcd-config` and `--export-lcd-config` to load or export a layout from the command line.
- Single-instance CLI for scripting the LCD.

## Fixes and performance
- USB recovers from suspend/resume instead of spinning a core.
- Interrupt frames are sized to the endpoint max packet size.
- Memory-full resets no longer blank the screen.
- GIF background frames are cached and fewer LCD redraws are sent.

## Other
- Kraken 2023 Elite is now marked as tested.
- UI polish: Phosphor icons, better text contrast, a consistent corner-radius scale and reduced-motion support.
- Remaining French strings translated to English.
