# NZXT CAM Linux v1.0.0

**First public release.** A native Linux replacement for NZXT CAM, for Kraken Elite coolers, built with Tauri 2 and Rust.

## Highlights
- English and French UI, picked from the browser language and switchable in Settings → General.
- Cooling screen with pump and GPU fan control, profiles and a fan curve editor for GPU and case fans.
- LCD and RGB control, CPU / GPU / liquid / pump monitoring, and saveable profiles.

## Notes
- Needs the udev rule from `src-tauri/resources/99-nzxt-kraken.rules` for USB access without sudo (`install.sh` sets it up).
